# 🛡️ Igroboom Nodes (Anti-Bot & Loader)

Универсальный шаблон Node.js сервера с встроенной CLI-проверкой на робота, стильной анимацией загрузки и защитой от пустых страниц (`about:blank`).

## ✨ Особенности
- 🔐 **CLI Проверка на робота:** Интерактивная головоломка с треугольником (для Windows/Linux/Termux).
- 📶 **Стильный Loader:** Анимация загрузки с заполнением символами `#`.
- 🛡️ **Anti-Blank защита:** Если страница не загрузилась, пользователь увидит красивое предупреждение вместо белого экрана или ошибки браузера.
- 🌐 **Кроссплатформенность:** Готовые скрипты для Windows (`.bat`/`.ps1`) и Linux/Termux (`.sh`).

## 🚀 Установка и запуск

### 💻 Для Windows
1. Установите [Node.js](https://nodejs.org/) (если ещё не установлен).
2. Скачайте архив из раздела [Releases](../../releases).
3. Распакуйте и запустите файлы по порядку:
   - `1-install.bat` — установка зависимостей.
   - `2-check.bat` — прохождение проверки на робота (используйте клавиши `A`, `D` и `Enter`).
   - `3-start-server.bat` — запуск сервера.
4. Откройте в браузере: `http://localhost:8080`

### 🐧 Для Linux / Termux (Android)
1. Установите Node.js: `pkg install nodejs` (для Termux) или `sudo apt install nodejs` (для Linux).
2. Распакуйте архив: `tar -xzvf servers-nodes.tgz`
3. Перейдите в папку: `cd igroboom-release`
4. Установите зависимости: `npm install`
5. Запустите сервер: `node server.js` (проверка на робота запустится автоматически в терминале).

## ⚙️ Как это работает?
1. При запуске сервера в терминале активируется режим проверки.
2. Скрипт просит подтвердить действие и предлагает переместить зелёный треугольник из нулей в целевую ячейку с помощью клавиш `A` и `D`.
3. После успешного нажатия `Enter` сервер разблокируется и начинает работу.
4. При переходе на `http://localhost:8080` пользователь видит анимацию загрузки. Если сервер не отвечает более 10 секунд, срабатывает защита и показывается экран с кнопкой "repload".

## 📦 Сборка архивов
Если вы хотите собрать архивы самостоятельно из исходного кода:
```bash
# Для Linux/Termux (.tgz)
tar -czvf servers-nodes.tgz .

# Для Windows (.zip)
zip -r servers-windows-nodes.zip .
```
